# Nikaz Web Studio

A modern portfolio website for Nicolae Ionut, showcasing web development projects and services.

## Overview
Nikaz Web Studio is a professional portfolio website designed to present web development projects and attract clients for creating websites.

## Features
- Modern and responsive design
- Portfolio showcase for three projects
- Services section detailing offerings
- Contact form and WhatsApp integration
- Smooth animations and interactions
